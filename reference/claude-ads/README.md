# Claude Ads — reference library

Paid-media reference documentation copied from
[agriciDaniel/claude-ads](https://github.com/agriciDaniel/claude-ads), MIT licensed,
on 2026-09-19. Copied **unedited** — nothing here is rewritten or summarised.

The software itself is a Python plugin for Claude Code in a terminal and is not
integrated into this platform. Only the written reference material was taken,
because that is the part that transfers.

## Not yet in the Vault

These files are **not** ingested into `knowledge_chunks`. They are here to be read
first and ingested second, so nothing lands in ATLAS's retrieval that has not been
judged useful. Several documents cover platforms this business does not run
(Amazon, Snapchat, X, Apple Search Ads); ingesting those would put answers about
Snapchat inside a Meta campaign run.
